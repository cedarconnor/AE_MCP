# Sources and provenance

Original synthesis for After Effects Uber MCP, researched 2026-10-10. The package
contains no copied upstream implementations, assets or skill bodies. Parameter
defaults are original recommendations rather than a standardized industry contract.
These sources were selectively inspected, not all executed or fully audited.
Commit links preserve the reviewed version; licensing shown is repository metadata.
The complete methodology and fetched-file hashes ship in the MCP package under
`docs/research/MOTION_SKILLS_REVIEW.md` and `docs/research/motion-skills-sources.json`.
